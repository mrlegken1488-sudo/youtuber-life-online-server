# Youtuber Life Online — starter server

Это начальный WebSocket-сервер присутствия: комнаты, вход/выход и обмен координатами игроков. Он сам по себе ещё не подключён к HTML-игре — пока клиент игры не будет изменён для WebSocket, игроки не появятся друг у друга.

## Размещение на Render

1. Загрузите **всю папку `online-server`** в отдельный GitHub-репозиторий. В корне репозитория должны лежать `server.js`, `package.json` и этот README (не оставляйте их внутри дополнительной вложенной папки).
2. На Render выберите **New + → Web Service** и подключите этот репозиторий.
3. Настройки: Runtime **Node**, Build Command `npm install`, Start Command `npm start`. Instance type можно начать с Free, если он доступен для вашего аккаунта.
4. После Deploy откройте выданный адрес с `/health`, например `https://ИМЯ.onrender.com/health`. Должен прийти JSON с `"ok":true`.
5. Адрес WebSocket для клиента будет `wss://ИМЯ.onrender.com`. Не вставляйте пароль/секреты в HTML и не публикуйте их на GitHub.

## Сообщения протокола v1

Клиент при подключении отправляет `{"type":"join","room":"city-1","nick":"Имя"}`. Сервер отвечает `welcome` со списком игроков, затем отправляет `joined`, `moved` и `left`. Позиция отправляется как `{"type":"move","x":1,"y":0,"z":2,"yaw":0}`. Ограничение — 20 игроков в комнате.

Пока сервер не проверяет пароль/сессию, не хранит аккаунты, прогресс или историю. Это демонстрационный транспорт позиций, а не готовая безопасная MMO-инфраструктура. Перед открытым публичным запуском нужны авторизация, лимиты/проверка движения, защита от злоупотреблений и политика CORS/Origin.
